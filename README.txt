ctyNet 인수인계 안내서
======================================

이 폴더 안에는 세 가지가 들어 있습니다.
- app      : 프로그램 소스 (깃허브가 윈도우에서 exe 실행 파일로 만들어 줍니다)
- .github  : 자동 빌드 설정 (손댈 필요 없음)
- site     : 웹사이트 (continyu.site 에 올립니다)

아래 순서대로 하면 됩니다. 명령어(터미널)는 전혀 필요 없고, 전부 웹 브라우저에서 합니다.
작업은 1번(깃허브) -> 2번(사이트 공개) -> 3번(도메인 연결) -> 4번(애드센스) 순서입니다.


======================================
1. 깃허브에 올려서 exe 자동으로 만들기
======================================

1) github.com 에 로그인합니다 (계정 shkwj99-netizen).

2) 오른쪽 위 + 버튼 -> New repository (새 저장소).
   - Repository name 에 정확히  ctynet  이라고 적습니다. (소문자, 꼭 이 이름)
   - Public 선택.
   - 아래 Create repository 클릭.

3) 만들어진 저장소 화면에서  uploading an existing file  이라는 파란 글씨를 누릅니다.
   (또는 Add file -> Upload files)

4) 이 안내서가 들어 있는 폴더에서  app  폴더와  .github  폴더를
   파일 올리는 칸으로 드래그해서 끌어다 놓습니다.
   - 두 폴더를 통째로 올리면 됩니다.
   - .github 폴더가 안 보이면, 파일 탐색기에서 "숨긴 항목 표시"를 켜세요.
   - 아래 초록색 Commit changes(변경 저장) 버튼을 누릅니다.

5) 올리고 나면 깃허브가 자동으로 윈도우에서 프로그램을 만들기 시작합니다.
   위쪽 메뉴의  Actions  탭에 들어가면 진행 상황이 보입니다.
   초록색 체크 표시가 되면 완료입니다 (보통 3~5분).

6) 저장소 첫 화면 오른쪽의  Releases  를 누르면  ctyNet.exe  파일이 생겨 있습니다.
   이 파일이 바로 사이트의 다운로드 버튼이 가리키는 파일입니다.

   ** 나중에 프로그램을 고치고 싶으면 **
   app 폴더의 파일을 고쳐서 같은 방법으로 다시 올리면(덮어쓰기),
   깃허브가 새 exe를 자동으로 만들어 Releases 에 올려 줍니다.
   사이트 다운로드 버튼은 항상 최신 파일을 가리키므로 따로 바꿀 필요가 없습니다.


======================================
2. 사이트를 Cloudflare Pages 로 공개하기
======================================

1) dash.cloudflare.com 에 로그인합니다 (없으면 무료 가입).

2) 왼쪽 메뉴에서  Workers & Pages  -> 가운데  Create  -> 위쪽  Pages 탭
   -> Connect to Git(깃 연결) 을 누릅니다.

3) 깃허브 연결을 허용하고,  ctynet  저장소를 선택합니다. Begin setup 을 누릅니다.

4) 빌드 설정 화면에서 아래처럼 맞춥니다. (중요)
   - Framework preset (프레임워크)  :  None
   - Build command (빌드 명령)       :  비워 둡니다 (아무것도 안 적음)
   - Build output directory (출력 폴더):  site
   아래  Save and Deploy  를 누릅니다.

5) 잠시 뒤  (무언가).pages.dev  주소가 생기고, 누르면 사이트가 열립니다.
   여기까지 하면 사이트는 이미 인터넷에 공개된 것입니다.


======================================
3. continyu.site 도메인 연결하기
======================================

방법 A (가장 쉬움, 권장): 도메인을 Cloudflare 로 옮기기
1) Cloudflare 첫 화면에서  + Add a domain  ->  continyu.site  입력 -> Free 요금제 선택.
2) Cloudflare 가 네임서버 2개를 알려 줍니다 (예: xxx.ns.cloudflare.com 두 개).
3) 가비아에 로그인 -> My가비아 -> 도메인 -> continyu.site -> 네임서버 설정 ->
   가비아 기본 네임서버 대신 위에서 받은 Cloudflare 네임서버 2개를 입력하고 저장합니다.
4) 반영까지 몇 시간 걸릴 수 있습니다. 반영되면 Cloudflare 에서 도메인이 Active 로 바뀝니다.
5) 다시  Workers & Pages -> ctynet 프로젝트 -> Custom domains(사용자 지정 도메인)
   -> Set up a custom domain -> continyu.site 입력 -> 안내대로 추가하면 끝입니다.
   (www 도 쓰고 싶으면 www.continyu.site 도 같은 방식으로 추가)

* 네임서버를 Cloudflare 로 바꾸면 continyu 채팅 사이트 등 기존에 가비아에서
  쓰던 다른 설정이 있다면 Cloudflare 쪽에도 같은 DNS 레코드를 다시 넣어야 합니다.
  continyu.site 를 새 사이트에만 쓸 거라면 신경 쓸 것 없습니다.

* 네임서버를 옮기기 싫다면, 가비아 DNS 설정에서 CNAME 레코드로
  Cloudflare Pages 가 안내하는 주소를 가리키게 하는 방법도 있습니다.
  (Custom domains 추가 시 Cloudflare 가 어떤 값을 넣으라고 알려 줍니다.)


======================================
4. 다운로드 버튼 주소 확인
======================================

사이트의 다운로드 버튼은 아래 주소를 가리킵니다.
  https://github.com/shkwj99-netizen/ctynet/releases/latest/download/ctyNet.exe

- 저장소를 계정 shkwj99-netizen, 이름 ctynet 으로 만들었다면 그대로 동작합니다.
- 만약 다른 이름으로 만들었다면, site/index.html 파일에서 위 주소를 본인 것으로 고쳐야 합니다.
  (index.html 안에서  releases/latest/download  를 찾으면 됩니다)


======================================
5. 구글 애드센스 붙이기 (사이트가 도메인에 연결되고 며칠 지난 뒤)
======================================

애드센스는 내용이 어느 정도 있고 도메인이 제대로 연결된 뒤 신청하는 것이 좋습니다.
승인은 시간이 걸리고 보장되지는 않습니다.

1) google.com/adsense 에서 가입하고 continyu.site 를 사이트로 추가합니다.

2) 애드센스가 "코드를 사이트에 넣으라"고 하면, 그 코드 안의  ca-pub-숫자  가 본인 게시자 ID 입니다.

3) site 폴더의 모든 html 파일 맨 위(<head> 안)에는 아래처럼 주석 처리된 줄이 있습니다.
     <!-- <script async src="...ca-pub-0000000000000000..."></script> -->
   -> ca-pub-0000000000000000 을 본인 번호로 바꾸고,
      앞의  <!--  와 뒤의  -->  를 지워서 살립니다.
   -> 고친 파일들을 깃허브 site 폴더에 다시 올리면(덮어쓰기) 사이트에 반영됩니다.

4) site/ads.txt 파일을 열어 안내대로 본인 pub 번호를 넣고 맨 앞의  #  을 지웁니다.

5) 광고가 들어갈 자리는 사이트에 "광고 영역" 이라고 표시된 상자들입니다.
   자동 광고를 켜거나, 광고 단위 코드를 그 자리에 넣으면 됩니다.


======================================
참고 (프로그램이 하는 일)
======================================

- ctyNet 은 내 컴퓨터에서 주요 서버까지의 응답 속도(핑)와,
  내 데이터가 거쳐 가는 경로를 세계지도 위에 보여 주는 진단 도구입니다.
- 속도를 빠르게 해 주거나 IP 를 숨기는 프로그램이 아닙니다 (VPN 아님).
- 측정은 내 컴퓨터 안에서 이루어지고, 측정 결과를 서버로 보내지 않습니다.
- 처음 실행할 때 "Windows의 PC 보호" 창이 나오면 추가 정보 -> 실행 을 누르면 됩니다.
  (서명 인증서가 없어서 나오는 안내이며, 유료 코드 서명 인증서를 넣으면 사라집니다.)
- IP 위치 정보는 DB-IP 의 무료 데이터를 사용합니다.
